# 🤖 AI Sales Buddy

AI Sales Buddy is an AI-powered sales assistant that communicates with customers, answers product-related questions, understands their intent, and automatically identifies potential leads.

🚀 Features
💬 AI-powered customer conversations
🧠 Intent detection
📊 Lead scoring
🔥 Hot / 🟡 Warm / ⚪ Cold classification
💾 Conversation & lead storage
📱 WhatsApp integration
📈 Basic lead dashboard
